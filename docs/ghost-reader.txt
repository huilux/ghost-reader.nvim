==============================================================================
1. Introduction                                    |ghost-reader-intro|

ghost-reader.nvim lets you read ebooks (EPUB, TXT, Markdown) inside Neovim
with three stealth modes that disguise book content as code. Features a
boss key that instantly switches to realistic code.

Requirements:
  - Neovim >= 0.10
  - `unzip` (for EPUB support)

==============================================================================
2. Setup                                           |ghost-reader-setup|

>lua
  -- lazy.nvim
  {
    "your-name/ghost-reader.nvim",
    cmd = "GhostReader",
    opts = {},
  }
<

>lua
  -- Manual
  require("ghost-reader").setup()
<

==============================================================================
3. Commands                                        |ghost-reader-commands|

:GhostReader <path>    Open an ebook file
:GhostReaderClose      Close current book
:GhostReaderMode <m>   Switch mode: minimal_diff|code_camouflage|dual_mode
:GhostReaderBoss       Activate boss mode (show fake code)
:GhostReaderRestore    Restore reading mode

==============================================================================
4. Configuration                                   |ghost-reader-config|

See |ghost-reader.nvim| README for full configuration options.

Default keymaps (all customizable via setup()):
  J / <C-d>       Next page
  K / <C-u>       Previous page
  ]c              Next chapter
  [c              Previous chapter
  mb              Add bookmark
  gb              List bookmarks
  gt              Table of contents
  gp              Show progress
  <Esc><Esc>      Boss key
  <leader>gr      Restore reading
  <leader>gm      Switch stealth mode

==============================================================================
5. Stealth Modes                                   |ghost-reader-modes|

minimal_diff       Content shown as-is with fake filetype and filename
code_camouflage    Book text disguised as code (variables, comments, logs)
dual_mode          Book text hidden inside multi-line comments/strings
