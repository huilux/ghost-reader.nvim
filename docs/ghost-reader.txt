==============================================================================
1. Introduction                                    |ghost-reader-intro|

ghost-reader.nvim lets you read ebooks (EPUB, TXT, Markdown) inside Neovim
with stealth modes that disguise book content as code. Features a boss key
that instantly switches back to your previous buffer.

Requirements:
  - Neovim >= 0.10
  - `unzip` (for EPUB support)

==============================================================================
2. Setup                                           |ghost-reader-setup|

>lua
  -- lazy.nvim
  {
    "huilux/ghost-reader.nvim",
    cmd = { "GhostReader", "GhostReaderClose", "GhostReaderBoss", "GhostReaderRestore", "GhostReaderStatusline" },
    keys = {
      { "<leader>go", function() require("ghost-reader").select_book() end, desc = "Open/resume" },
      { "<leader>gq", function() require("ghost-reader").close() end,       desc = "Quit" },
      { "<leader>gt", function() require("ghost-reader").toc() end,         desc = "TOC" },
    },
    opts = {},
  }
<

==============================================================================
3. Commands                                        |ghost-reader-commands|

:GhostReader [path]        Open an ebook (no arg shows book history)
:GhostReaderClose          Close current book
:GhostReaderStatusline     Open in statusline mode (bottom float win)
:GhostReaderBoss           Activate boss key (switch to previous buffer)
:GhostReaderRestore        Restore reading after boss key

==============================================================================
4. Configuration                                   |ghost-reader-config~

>lua
  opts = {
    boss_key = {
      keys = "<Esc><Esc>",
      use_current_buffer = true,
      preset = "random",
    },
    statusline = {
      interval = 3000,   -- auto-advance interval in ms
      mode = "auto",     -- "auto" or "manual"
    },
  }
<

==============================================================================
5. Reading Modes                                   |ghost-reader-modes~

sparse_notes (fullscreen) ~
  Book text is disguised as TODO/FIXME comments scattered throughout real
  code (from your open buffers). Long lines wrap at 80 columns.

statusline (bottom float window) ~
  A 1-row floating window at the bottom shows one line at a time. Supports
  auto-advance (configurable interval) and manual (J/K) modes. Long text
  is split into screen-width chunks.

==============================================================================
6. Keymaps                                         |ghost-reader-keymaps~

Global (available in any buffer):
  <leader>go    Open book / resume reading (smart)
  <leader>gq    Close fullscreen reader
  <leader>gt    Table of contents

Fullscreen mode (buffer-local):
  J             Jump to next content line (auto page turn)
  K             Jump to previous content line (auto page turn)
  ]c            Next chapter
  [c            Previous chapter
  gp            Show progress
  <leader>gt    Table of contents
  <Esc><Esc>    Boss key (switch to previous buffer)

Statusline mode (buffer-local):
  J             Next line/chunk
  K             Previous line/chunk
  <leader>g+    Speed up (-500ms)
  <leader>g-    Slow down (+500ms)
  <leader>gm    Toggle auto/manual
  <leader>gq    Stop statusline reader
  <Esc><Esc>    Boss key (hide float window)

Boss key recovery:
  <leader>go    Restore reading from any state
