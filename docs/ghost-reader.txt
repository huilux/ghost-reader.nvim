==============================================================================
1. Introduction                                    |ghost-reader-intro|

ghost-reader.nvim lets you read ebooks (EPUB, TXT, Markdown) inside Neovim
with three user-facing modes:

  - overlay: the default real-buffer extmark reader
  - statusline: a one-line floating reader above the native statusline
  - mirror: a code-like scratch buffer with configurable disguise styles

When overlay cannot attach cleanly, the plugin falls back to mirror
automatically. That fallback keeps the session usable, but it is still only a
visual layer. Concealment is not a security boundary.

Requirements:
  - Neovim 0.10+
  - `unzip` for EPUB support
  - Plenary for tests only

==============================================================================
2. Setup                                           |ghost-reader-setup|

>lua
  {
    "huilux/ghost-reader.nvim",
    cmd = {
      "GhostReader",
      "GhostReaderStatusline",
    },
    keys = {
      { "<leader>rr", function() require("ghost-reader").open() end, desc = "Open reading" },
    },
    opts = {},
  }
<

The `keys` table belongs to lazy.nvim. It provides the single entry point that
can load the plugin before a reading session exists. Every press selects a
book and then selects overlay, statusline, or mirror mode. After loading, Ghost Reader
registers the remaining global and buffer-local reading mappings, so they do
not need to be duplicated in both `keys` and `opts.keymaps`.

==============================================================================
3. Commands                                        |ghost-reader-commands|

:GhostReader [path]        Pick an ebook if needed, then pick a reading mode
:GhostReaderClose          Close the current session
:GhostReaderHide            Hide or restore the current session
:GhostReaderStatusline     Open in statusline mode
:GhostReaderToc             Open the table of contents

==============================================================================
4. Overlay                                         |ghost-reader-overlay|

overlay is the default mode.

  - It renders book content onto the real buffer with extmarks and virtual
    lines.
  - It does not rewrite the buffer text, name, filetype, or modified state.
  - If the real-buffer renderer cannot attach cleanly, the plugin falls back
    to mirror.

==============================================================================
5. Buffer                                          |ghost-reader-buffer|

buffer mode uses an anonymous scratch buffer as a visual code disguise. The
source buffer is saved and restored without changing its text or undo history.
The renderer writes book lines as valid comments and keeps a stable code
skeleton for the duration of the session.

Two styles are available through `buffer.style`:

  - light: reading lines are grouped together for easier reading
  - strong: reading lines are distributed through the code skeleton

`j` and `k` move the cursor between reading lines and skip skeleton code.
`buffer.<style>.visible_lines` controls the number of book lines loaded in one
view. `buffer.<style>.max_consecutive_lines` limits the number of adjacent book
lines in each group. The defaults are light `6/6` and strong `3/1`.

==============================================================================
6. Statusline                                      |ghost-reader-statusline|

statusline mode uses a one-line floating window above the native Vim or
lualine statusline. It follows changes to `laststatus`, `cmdheight`, editor
size, and window layout without covering native status information.

  - `j` and `k` move by line or segment.
  - `a` toggles autoplay.
  - `+` and `-` adjust autoplay speed.
  - Long text is wrapped by display width.

==============================================================================
7. Reading keys                                    |ghost-reader-keys|

Global mappings:

  <leader>rr    Select a book and reading mode
  <Esc><Esc>    Hide or restore the current session
  <leader>rt    Open the table of contents
  <leader>rq    Close the current session

Visible-reading mappings:

  j             Next content
  k             Previous content
  <C-f>         Next page
  <C-b>         Previous page
  ]]            Next chapter
  [[            Previous chapter
  t             Table of contents
  g%            Show progress
  q             Close session
  ?             Help

==============================================================================
8. Stealth events                                  |ghost-reader-stealth|

The stealth layer can hide the session automatically on:

  - Insert mode entry
  - Buffer leave
  - Window leave
  - Focus lost

`<Esc><Esc>` toggles between visible and hard-hidden states. Hard hiding
restores captured mappings; restoring immediately installs the reading keys
again. A single `<Esc>` keeps its native Neovim behavior. Keys not configured
as reading keys also keep their native behavior.

While statusline reading stays visible, mappings move from the old buffer to
the current buffer when windows or buffers change. The float and autoplay keep
running. Overlay still soft-hides during Insert mode; hard hide events restore
the captured Normal-mode mappings.

==============================================================================
9. Configuration                                   |ghost-reader-config|

Every option below is optional. `keymaps.global` controls global mappings
after the plugin loads. `keymaps.reader` and `keymaps.statusline` control
buffer-local mappings while reading is visible. When changing `global.open`,
update the matching lazy.nvim `keys` entry as well so the first key press can
load the plugin. With lazy.nvim, place the contents of the `setup({ ... })`
table under `opts`; call `setup()` directly only for a manual configuration.

>lua
  require("ghost-reader").setup({
    reader = {
      renderer = "overlay",
      visible_blocks = 3,
      mirror_fallback = true,
    },
    buffer = {
      style = "light",
      preset = "random",
      light = {
        visible_lines = 6,
        max_consecutive_lines = 6,
      },
      strong = {
        visible_lines = 3,
        max_consecutive_lines = 1,
      },
    },
    statusline = {
      interval = 3000,
      autoplay = true,
      page_step = 5,
    },
    stealth = {
      hide_on_focus_lost = true,
      silent = true,
      overlay = {
        hide_on_insert = true,
        hide_on_buf_leave = true,
        hide_on_win_leave = true,
      },
    },
    paths = {
      cache_dir = vim.fn.stdpath("cache") .. "/ghost-reader/",
      data_dir = vim.fn.stdpath("data") .. "/ghost-reader/",
    },
    keymaps = {
      global = {
        open = "<leader>rr",
        hide = "<Esc><Esc>",
        toc = "<leader>rt",
        close = "<leader>rq",
      },
      reader = {
        next_content = "j",
        prev_content = "k",
        next_page = "<C-f>",
        prev_page = "<C-b>",
        next_chapter = "]]",
        prev_chapter = "[[",
        toc = "t",
        progress = "g%",
        hide = false,
        close = "q",
        help = "?",
      },
      statusline = {
        toggle_auto = "a",
        faster = "+",
        slower = "-",
      },
    },
  })
<

==============================================================================
10. Troubleshooting                                |ghost-reader-troubleshooting|

If `:GhostReaderStatusline` opens nothing, check that the current buffer is
still valid and that another plugin has not replaced the window.

If overlay does not attach, mirror fallback should keep the session alive.

If the session appears blank, check `visible_blocks`, the current window width,
and whether the source file is readable text.
