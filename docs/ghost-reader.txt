1. Introduction                                    |ghost-reader-intro|

ghost-reader.nvim lets you read ebooks (EPUB, TXT, Markdown) inside Neovim
with two user-facing modes:

  - overlay: the default real-buffer extmark reader
  - statusline: a one-line floating reader at the bottom of the screen

When overlay cannot attach cleanly, the plugin falls back to mirror
automatically. That fallback keeps the session usable, but it is still only a
visual layer. Concealment is not a security boundary.

Requirements:
  - Neovim 0.10+
  - `unzip` for EPUB support
  - Plenary for tests only

2. Setup                                           |ghost-reader-setup|

>lua
  {
    "huilux/ghost-reader.nvim",
    cmd = {
      "GhostReader",
      "GhostReaderClose",
      "GhostReaderControl",
      "GhostReaderHide",
      "GhostReaderStatusline",
      "GhostReaderToc",
    },
    keys = {
      { "<leader>rr", function() require("ghost-reader").open() end, desc = "Open or resume reading" },
      { "<leader>rs", function() require("ghost-reader").open_statusline() end, desc = "Open statusline reader" },
      { "<leader>rm", function() require("ghost-reader.actions").control() end, desc = "Toggle reading controls" },
      { "<leader>rh", function() require("ghost-reader.actions").hide() end, desc = "Hide or restore session" },
      { "<leader>rt", function() require("ghost-reader").toc() end, desc = "Open table of contents" },
      { "<leader>rq", function() require("ghost-reader").close() end, desc = "Close reading session" },
    },
    opts = {
      reader = {
        renderer = "overlay",
        visible_blocks = 3,
        mirror_fallback = true,
      },
      statusline = {
        interval = 3000,
        autoplay = true,
        page_step = 5,
      },
      stealth = {
        hide_on_focus_lost = true,
        silent = true,
        overlay = {
          hide_on_insert = true,
          hide_on_buf_leave = true,
          hide_on_win_leave = true,
        },
      },
      paths = {},
      keymaps = {
        global = {
          open = "<leader>rr",
          statusline = "<leader>rs",
          control = "<leader>rm",
          hide = "<leader>rh",
          toc = "<leader>rt",
          close = "<leader>rq",
        },
        controls = {
          next_content = "j",
          prev_content = "k",
          next_page = "<C-f>",
          prev_page = "<C-b>",
          next_chapter = "]]",
          prev_chapter = "[[",
          toc = "t",
          progress = "g%",
          hide = "gh",
          close = "q",
          help = "?",
          exit_controls = "<Esc>",
        },
        statusline = {
          toggle_auto = "a",
          faster = "+",
          slower = "-",
        },
      },
    },
  }

==============================================================================
3. Commands                                        |ghost-reader-commands|

:GhostReader [path]        Open an ebook or pick from history
:GhostReaderClose          Close the current session
:GhostReaderControl        Toggle the reading control layer
:GhostReaderHide            Hide or restore the current session
:GhostReaderStatusline     Open in statusline mode
:GhostReaderToc             Open the table of contents

==============================================================================
4. Overlay                                         |ghost-reader-overlay|

overlay is the default mode.

  - It renders book content onto the real buffer with extmarks and virtual
    lines.
  - It does not rewrite the buffer text, name, filetype, or modified state.
  - If the real-buffer renderer cannot attach cleanly, the plugin falls back
    to mirror.

==============================================================================
5. Statusline                                      |ghost-reader-statusline|

statusline mode uses a one-line floating window at the bottom of the screen.

  - `j` and `k` move by line or segment.
  - `a` toggles autoplay.
  - `+` and `-` adjust autoplay speed.
  - Long text is wrapped by display width.

==============================================================================
6. Controls                                        |ghost-reader-controls|

Global mappings:

  <leader>rr    Open or resume reading
  <leader>rs    Open statusline reader
  <leader>rm    Toggle reading controls
  <leader>rh    Hide or restore the current session
  <leader>rt    Open the table of contents
  <leader>rq    Close the current session

Control layer mappings:

  j             Next content
  k             Previous content
  <C-f>         Next page
  <C-b>         Previous page
  ]]            Next chapter
  [[            Previous chapter
  t             Table of contents
  g%            Show progress
  gh            Hard hide session
  q             Close session
  ?             Help
  <Esc>         Exit controls

==============================================================================
7. Stealth events                                  |ghost-reader-stealth|

The stealth layer can hide the session automatically on:

  - Insert mode entry
  - Buffer leave
  - Window leave
  - Focus lost

`gh` performs a hard hide and restores the captured mappings. `<Esc>` only
exits the control layer.

==============================================================================
9. Troubleshooting                                 |ghost-reader-troubleshooting|

If `:GhostReaderStatusline` opens nothing, check that the current buffer is
still valid and that another plugin has not replaced the window.

If overlay does not attach, mirror fallback should keep the session alive.

If the session appears blank, check `visible_blocks`, the current window width,
and whether the source file is readable text.
