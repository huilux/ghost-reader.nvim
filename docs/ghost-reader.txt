==============================================================================
1. Introduction                                    |ghost-reader-intro|

ghost-reader.nvim lets you read ebooks (EPUB, TXT, Markdown) inside Neovim
with an overlay mode that keeps book content in the real buffer and a
statusline mode that shows a one-line floating reader.

Requirements:
  - Neovim >= 0.10
  - `unzip` (for EPUB support)

==============================================================================
2. Setup                                           |ghost-reader-setup|

>lua
  -- lazy.nvim
  {
    "huilux/ghost-reader.nvim",
    cmd = { "GhostReader", "GhostReaderClose", "GhostReaderControl", "GhostReaderHide", "GhostReaderStatusline", "GhostReaderToc" },
    keys = {
      { "<leader>rr", function() require("ghost-reader").open() end, desc = "Open/resume" },
      { "<leader>rs", function() require("ghost-reader").open_statusline() end, desc = "Statusline reader" },
      { "<leader>rq", function() require("ghost-reader").close() end, desc = "Quit" },
    },
    opts = {
      reader = { renderer = "overlay", visible_blocks = 3 },
      statusline = { interval = 3000, autoplay = true, page_step = 5 },
      stealth = { hide_on_focus_lost = true, silent = true },
    },
  }
<

==============================================================================
3. Commands                                        |ghost-reader-commands|

:GhostReader [path]        Open an ebook (no arg shows book history)
:GhostReaderClose          Close current book
:GhostReaderControl        Toggle reading controls
:GhostReaderHide            Hide or restore the active session
:GhostReaderStatusline     Open in statusline mode (bottom float win)
:GhostReaderToc             Open table of contents

==============================================================================
5. Reading Modes                                   |ghost-reader-modes~

overlay (default) ~
  Book content is drawn over the real buffer with virtual lines. The file
  contents remain unchanged.

statusline (bottom float window) ~
  A 1-row floating window at the bottom shows one line at a time. Supports
  auto-advance (configurable interval) and manual (J/K) modes. Long text
  is split into screen-width chunks.

==============================================================================
6. Keymaps                                         |ghost-reader-keymaps~

Global (available in any buffer):
  <leader>rr    Open book / resume reading
  <leader>rs    Open statusline reader
  <leader>rq    Close the active session
  <leader>rt    Table of contents

Control layer (buffer-local):
  j             Next content
  k             Previous content
  <C-f>         Next page
  <C-b>         Previous page
  ]]            Next chapter
  [[            Previous chapter
  t             Table of contents
  g%            Show progress
  gh            Hide session
  q             Close session
  ?             Help
  <Esc>         Exit controls

Statusline mode (buffer-local):
  a             Toggle autoplay
  +             Speed up
  -             Slow down
  <Esc>         Exit controls
