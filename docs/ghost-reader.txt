==============================================================================
1. Introduction                                    |ghost-reader-intro|

ghost-reader.nvim lets you read ebooks (EPUB, TXT, Markdown) inside Neovim
with two user-facing modes:

  - overlay: the default real-buffer extmark reader
  - statusline: a one-line floating reader at the bottom of the screen

When overlay cannot attach cleanly, the plugin falls back to mirror
automatically. That fallback keeps the session usable, but it is still only a
visual layer. Concealment is not a security boundary.

Requirements:
  - Neovim 0.10+
  - `unzip` for EPUB support
  - Plenary for tests only

==============================================================================
2. Setup                                           |ghost-reader-setup|

>lua
  {
    "huilux/ghost-reader.nvim",
    cmd = {
      "GhostReader",
      "GhostReaderStatusline",
    },
    keys = {
      { "<leader>rr", function() require("ghost-reader").open() end, desc = "Open reading" },
      { "<leader>rs", function() require("ghost-reader").open_statusline() end, desc = "Open statusline reader" },
    },
    opts = {},
  }
<

The `keys` table belongs to lazy.nvim. It provides only the two entry points
that can load the plugin before a reading session exists. After loading,
Ghost Reader registers the remaining global mappings and the buffer-local
control mappings from its defaults, so those mappings do not need to be
duplicated in both `keys` and `opts.keymaps`.

==============================================================================
3. Commands                                        |ghost-reader-commands|

:GhostReader [path]        Open an ebook or pick from history
:GhostReaderClose          Close the current session
:GhostReaderControl        Toggle the reading control layer
:GhostReaderHide            Hide or restore the current session
:GhostReaderStatusline     Open in statusline mode
:GhostReaderToc             Open the table of contents

==============================================================================
4. Overlay                                         |ghost-reader-overlay|

overlay is the default mode.

  - It renders book content onto the real buffer with extmarks and virtual
    lines.
  - It does not rewrite the buffer text, name, filetype, or modified state.
  - If the real-buffer renderer cannot attach cleanly, the plugin falls back
    to mirror.

==============================================================================
5. Statusline                                      |ghost-reader-statusline|

statusline mode uses a one-line floating window at the bottom of the screen.

  - `j` and `k` move by line or segment.
  - `a` toggles autoplay.
  - `+` and `-` adjust autoplay speed.
  - Long text is wrapped by display width.

==============================================================================
6. Controls                                        |ghost-reader-controls|

Global mappings:

  <leader>rr    Open reading
  <leader>rs    Open statusline reader
  <leader>rm    Toggle reading controls
  <Esc><Esc>    Hide or restore the current session
  <leader>rt    Open the table of contents
  <leader>rq    Close the current session

Control layer mappings:

  j             Next content
  k             Previous content
  <C-f>         Next page
  <C-b>         Previous page
  ]]            Next chapter
  [[            Previous chapter
  t             Table of contents
  g%            Show progress
  q             Close session
  ?             Help

==============================================================================
7. Stealth events                                  |ghost-reader-stealth|

The stealth layer can hide the session automatically on:

  - Insert mode entry
  - Buffer leave
  - Window leave
  - Focus lost

`<Esc><Esc>` toggles between visible and hard-hidden states. Hiding exits the
control layer and restores captured mappings. Restoring overlay or mirror
re-enters controls; restoring statusline leaves controls inactive. A single
`<Esc>` keeps its native Neovim behavior, and `<leader>rm` alone toggles the
control layer.

If `keymaps.controls.exit_controls` is explicitly set back to `<Esc>`, that
buffer-local prefix takes precedence over the global `<Esc><Esc>` mapping.
Configure hide to a sequence without the `<Esc>` prefix in that case.

==============================================================================
8. Configuration                                   |ghost-reader-config|

Every option below is optional. `keymaps.global` controls global mappings
after the plugin loads. `keymaps.controls` and `keymaps.statusline` control
buffer-local mappings inside a reading session. When changing `global.open`
or `global.statusline`, update the matching lazy.nvim `keys` entry as well so
the first key press can load the plugin. With lazy.nvim, place the contents of
the `setup({ ... })` table under `opts`; call `setup()` directly only for a
manual configuration.

>lua
  require("ghost-reader").setup({
    reader = {
      renderer = "overlay",
      visible_blocks = 3,
      mirror_fallback = true,
    },
    statusline = {
      interval = 3000,
      autoplay = true,
      page_step = 5,
    },
    stealth = {
      hide_on_focus_lost = true,
      silent = true,
      overlay = {
        hide_on_insert = true,
        hide_on_buf_leave = true,
        hide_on_win_leave = true,
      },
    },
    paths = {
      cache_dir = vim.fn.stdpath("cache") .. "/ghost-reader/",
      data_dir = vim.fn.stdpath("data") .. "/ghost-reader/",
    },
    keymaps = {
      global = {
        open = "<leader>rr",
        statusline = "<leader>rs",
        control = "<leader>rm",
        hide = "<Esc><Esc>",
        toc = "<leader>rt",
        close = "<leader>rq",
      },
      controls = {
        next_content = "j",
        prev_content = "k",
        next_page = "<C-f>",
        prev_page = "<C-b>",
        next_chapter = "]]",
        prev_chapter = "[[",
        toc = "t",
        progress = "g%",
        hide = false,
        close = "q",
        help = "?",
        exit_controls = false,
      },
      statusline = {
        toggle_auto = "a",
        faster = "+",
        slower = "-",
      },
    },
  })
<

==============================================================================
9. Troubleshooting                                 |ghost-reader-troubleshooting|

If `:GhostReaderStatusline` opens nothing, check that the current buffer is
still valid and that another plugin has not replaced the window.

If overlay does not attach, mirror fallback should keep the session alive.

If the session appears blank, check `visible_blocks`, the current window width,
and whether the source file is readable text.
